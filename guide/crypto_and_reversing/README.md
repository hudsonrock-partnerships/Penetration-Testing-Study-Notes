# Cryptography & Reverse Engineering

This section explores cryptographic concepts, encryption weaknesses, and reverse engineering techniques used in penetration testing and malware analysis.

## Beginner
- Learn basic cryptographic principles: symmetric vs asymmetric encryption, hashing, and encoding.
- Practice using tools like OpenSSL or Hashcat to encrypt, decrypt, and crack hashes.
- Understand common crypto vulnerabilities such as weak cipher modes, insecure key management, and predictable random number generation.

## Intermediate
- Analyze and exploit crypto implementations, including padding oracle attacks, CBC bit flipping, and JWT signature bypass.
- Reverse engineer simple binaries using tools like Ghidra or IDA Free to understand program flow and extract secrets.
- Explore common obfuscation techniques and how to bypass them.

## Advanced
- Perform in-depth analysis of complex binaries and malware, including decompilation, dynamic debugging, and unpacking.
- Develop custom scripts or use frameworks to automate reverse engineering tasks and vulnerability discovery.
- Study advanced cryptographic attacks (e.g., differential and side-channel attacks) and assess the security of custom crypto schemes.
