# Reconnaissance

In this phase, you'll gather information about the target environment using open‑source intelligence (OSINT), network scanning, and enumeration. Effective reconnaissance sets the stage for identifying attack vectors and vulnerabilities.

## Beginner
- Understanding the importance of reconnaissance.
- Performing basic DNS and WHOIS lookups.
- Using tools like `nmap` for simple host discovery.

## Intermediate
- Subdomain enumeration (e.g., with Sublist3r, assetfinder).
- Port scanning and service enumeration strategies.
- Passive reconnaissance with search engines and public records.

## Advanced
- Automated reconnaissance workflows.
- Custom scripts for large‑scale asset discovery.
- Leveraging vulnerability scanners for initial assessments.
