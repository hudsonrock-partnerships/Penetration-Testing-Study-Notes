# Penetration Testing Guide

Welcome to the guide section of the Penetration Testing Study Notes repository. This area is designed to be a structured, modular reference that guides you through the various phases of penetration testing, from basic preparation to advanced post‑exploitation techniques.

Each subdirectory under `guide` corresponds to a distinct phase or topic in penetration testing. Inside each folder you'll find curated notes, tutorials, and cheat sheets organised by skill level (Beginner, Intermediate, Advanced).

Please refer to the root README for an overview and table of contents.
