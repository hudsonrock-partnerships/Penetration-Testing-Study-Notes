# Penetration Testing Guide

Welcome to the guide section of the Penetration Testing Study Notes repository. This area is designed to be a structured, modular reference that guides you through the various phases and specialty topics in penetration testing, from basic preparation to post-exploitation techniques.

Each subdirectory under `guide` corresponds to a distinct phase or topic. Inside each folder you'll find curated notes, tutorials and cheat sheets organised by skill level (Beginner, Intermediate, Advanced).

## Table of Contents

- [Preparation](preparation) – environment setup, basic command-line skills, and tool installation.
- [Reconnaissance](reconnaissance) – open-source intelligence, network scanning, and enumeration.
- [Vulnerability Discovery](vulnerability_discovery) – content discovery, fuzzing, scanning and vulnerability analysis.
- [Exploitation](exploitation) – exploiting discovered vulnerabilities including buffer overflows and web exploits.
- [Post Exploitation](post_exploitation) – persistence, privilege escalation, credential harvesting and lateral movement.
- [Web](web) – web-specific attacks including SQL injection, XSS, file uploads and bypass techniques.
- [Networking](networking) – network fundamentals, protocol analysis, service exploitation and wireless attacks.
- [Social Engineering](social_engineering) – phishing, pretexting and human‑focused attack techniques.
- [Cryptography and Reversing](crypto_and_reversing) – cryptographic attacks, decryption workflows and reverse engineering.
- [Cheat Sheets](cheat_sheets) – quick reference commands and payloads across all phases.

Use these links to navigate to the section you need. As the guide evolves, more topics and depth will be added. Contributions are welcome—please submit pull requests with improvements or additional resources.
