# Preparation

This section covers the basics and preparatory tasks required before starting a penetration test. It includes environment setup, virtualization, tool installation, and foundational knowledge necessary to proceed through the rest of the guide.

## Beginner
- Introduction to penetration testing ethics and methodology.
- Setting up a lab environment with virtual machines.
- Installing essential tools (e.g., Kali Linux, Metasploit, Burp Suite).

## Intermediate
- Configuring network infrastructure for testing.
- Scripting basics and automation.
- Understanding common protocols and operating systems.

## Advanced
- Customising toolchains and environments for specific engagements.
- Advanced configuration of proxies and debuggers.
- Creating and using custom wordlists and payloads.
