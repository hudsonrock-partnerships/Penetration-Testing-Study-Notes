# Cheat Sheets

This section consolidates quick-reference commands, payloads, and checklists for penetration testing activities across all stages. It provides concise cheat sheets so you can find the right command or syntax without sifting through lengthy notes.

## Using the cheat sheets

- Review the cheat sheet for a topic to refresh your memory on common tools and commands.
- Cross-reference with the deeper explanations and tutorials in other sections of the guide when you need context.
- Contribute your own snippets and commands to keep the cheat sheets comprehensive and up to date.

## Available cheat sheets

- **Command-line basics** – file and directory operations, permissions, networking commands.
- **Enumeration tools** – `nmap` options, `masscan`, `ldapsearch`, and SMB enumeration commands.
- **Web exploitation payloads** – SQL injection payloads, cross-site scripting vectors, file upload bypass techniques.
- **Buffer overflow templates** – pattern creation, offset calculation, bad character checks, and exploit skeletons.
- **Post-exploitation commands** – privilege escalation checks, password retrieval, lateral movement, persistence techniques.
- **Cryptography and reversing references** – common hashing commands, decryption workflows, reverse engineering shortcuts.

Check out each cheat sheet within this folder for more details.
