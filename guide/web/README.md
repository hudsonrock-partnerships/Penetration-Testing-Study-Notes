# Web Exploitation

Web applications are a common attack surface. This section covers the principles of web vulnerability discovery and exploitation, from understanding HTTP and OWASP Top 10 vulnerabilities to advanced exploitation techniques and defenses.

## Beginner
- Learn the basics of HTTP, request/response structure, and common headers.
- Study the OWASP Top Ten web application security risks.
- Use proxy tools like Burp Suite or OWASP ZAP to intercept and modify requests.
- Practice basic reconnaissance: directory and file enumeration using tools like DirBuster or Gobuster.

## Intermediate
- Perform vulnerability scanning with tools like Nikto or OWASP ZAP.
- Explore injection vulnerabilities such as SQL injection and command injection, including manual exploitation and automated payloads.
- Identify and exploit cross-site scripting (XSS) vulnerabilities, both reflected and stored.
- Bypass authentication and authorization controls through session manipulation or insecure direct object references (IDOR).

## Advanced
- Conduct advanced attacks such as server-side request forgery (SSRF), XML external entity (XXE) injection, and insecure deserialization.
- Develop custom scripts and payloads to automate exploitation and chain multiple vulnerabilities.
- Explore remote code execution (RCE) techniques and sandbox escape scenarios.
- Study mitigation strategies and how to perform defense-in-depth assessments for web applications.
