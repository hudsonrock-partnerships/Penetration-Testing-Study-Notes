# Penetration Testing Study Notes

This repository is a comprehensive collection of commands, tools, techniques and notes for penetration testing. Whether you’re just getting started or honing advanced skills, you’ll find curated resources here.

## Getting Started

The **guide** directory provides a structured, phase-based curriculum covering preparation, reconnaissance, vulnerability discovery, exploitation, post exploitation and more. Each section includes beginner, intermediate and advanced material along with tutorials and cheat sheets.

See [`guide/README.md`](guide/README.md) for an overview and table of contents.

## Additional Resources

- **scripts** – helper scripts and utilities.
- **Nuclei-Templates-Collection** – templates for the Nuclei vulnerability scanner.
- **hacktricks** – external reference repository included as a submodule.
- **research** – miscellaneous notes and drafts.
